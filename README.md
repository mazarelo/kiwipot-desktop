# Kiwipot for Windows, macOS and Linux

[Kiwipot](https://kiwipot.com) is notes, voice notes, tasks and places, on every device. This repository holds the
desktop app's releases: the downloads, and the updates the installed app looks for. The app itself is built from
Kiwipot's own repository.

## Download

From the [latest release](https://github.com/mazarelo/kiwipot-desktop/releases/latest):

| | |
|---|---|
| Windows | [`kiwipot-setup.exe`](https://github.com/mazarelo/kiwipot-desktop/releases/latest/download/kiwipot-setup.exe) |
| Linux | [`kiwipot-x86_64.AppImage`](https://github.com/mazarelo/kiwipot-desktop/releases/latest/download/kiwipot-x86_64.AppImage) or [`kiwipot-amd64.deb`](https://github.com/mazarelo/kiwipot-desktop/releases/latest/download/kiwipot-amd64.deb) |
| macOS | [`kiwipot-universal.dmg`](https://github.com/mazarelo/kiwipot-desktop/releases/latest/download/kiwipot-universal.dmg), for Apple silicon and Intel |

The app is a window on kiwipot.com: your notes are your Kiwipot account's, and it signs in like the website. On top of
the website it keeps running in the tray (in the Dock on a Mac), so reminders ring with the window closed, starts with
the computer if you want, and opens a new note from anywhere with Ctrl+Alt+N (⌥⌘N on a Mac).

The Windows installer isn't signed yet: Windows may say it protected your PC. Choose **More info**, then **Run
anyway**. On a Mac, open the `.dmg` and drag Kiwipot into Applications: it is signed and notarized by Apple, so it
opens without a warning. The app updates itself from here.
